# Edge MCP + Separate AI Agent Simulator

This solution has two separate C# applications:

```text
EdgebasedMCP       = simulated edge device + local MCP server
AiAgentSimulator  = separate AI-agent-style client that connects to MCP over HTTP
```

This matches the architecture:

```text
Edge Device + MCP Server  <--- HTTP/MCP request-response --->  AI Agent
```

The edge device simulates timestamped temperature telemetry. It does not read your computer's real temperature.

## 1. Start The Edge/MCP Side First

In PowerShell:

```powershell
cd C:\Users\posti\source\repos\EdgebasedMCP
dotnet run --project .\EdgebasedMCP\EdgebasedMCP.csproj
```

You should see:

```text
Simulated edge device is starting.
Telemetry will be generated every 5 seconds and printed here.
MCP endpoint for an AI agent: http://localhost:5050/mcp
Start AiAgentSimulator in a second terminal to request telemetry from MCP.

[EDGE -> MCP] seq=1 sentAtUtc=... sentAtUnixMs=... temperatureCelsius=22.12
[EDGE -> MCP] seq=2 sentAtUtc=... sentAtUnixMs=... temperatureCelsius=22.45
```

Leave this running.

## 2. Start The AI Agent Side Second

Open a second PowerShell window:

```powershell
cd C:\Users\posti\source\repos\EdgebasedMCP
dotnet run --project .\AiAgentSimulator\AiAgentSimulator.csproj
```

You should see:

```text
AI agent simulator is starting.
MCP server URL: http://localhost:5050/mcp
The agent will request telemetry every 15 seconds.

[AI -> MCP] initialize sent
[MCP -> AI] initialize response received

[AI -> MCP] requesting get_temperature_telemetry
[MCP -> AI] seq=2 sentAtUtc=... tempC=22.45 edgeToAiLatencyMs=1234 requestRoundTripMs=12.3
```

This proves the AI-agent side can receive telemetry from the edge/MCP side.

## What To Watch

In the edge/MCP window:

```text
[EDGE -> MCP] seq=3 ...
[MCP -> AI] served tool seq=3 ...
```

In the AI-agent window:

```text
[AI -> MCP] requesting get_temperature_telemetry
[MCP -> AI] seq=3 ...
```

If the `seq` number appears on both sides, the telemetry was generated by the edge device, stored in MCP, requested by the AI agent, and received by the AI agent.

6. Start debugging.

## Running On Different Machines

If the AI agent is on another machine, the edge/MCP app must listen on a network-accessible address.

On the edge machine, run:

```powershell
dotnet run --project .\EdgebasedMCP\EdgebasedMCP.csproj --urls http://0.0.0.0:5050
```

Find the edge machine IP address, for example:

```powershell
ipconfig
```

Then on the AI-agent machine, run:

```powershell
dotnet run --project .\AiAgentSimulator\AiAgentSimulator.csproj http://EDGE_MACHINE_IP:5050/mcp
```

Example:

```powershell
dotnet run --project .\AiAgentSimulator\AiAgentSimulator.csproj http://192.168.1.50:5050/mcp
```

You may need to allow port `5050` through the edge machine firewall.

## Important Files

- `EdgebasedMCP/Program.cs`: simulated edge device and MCP server.
- `AiAgentSimulator/Program.cs`: separate AI-agent-style MCP client.
- `EdgebasedMCP/EdgebasedMCP.http`: manual MCP test requests.
